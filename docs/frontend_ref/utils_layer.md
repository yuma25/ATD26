# 🖥️ フロントエンド・リファレンス：Utils & Types Layer (共通処理と型定義)

本ドキュメントは，フロントエンド全体で共有されるユーティリティ関数（`frontend/lib/`）およびグローバルな型定義（`frontend/types/`）の役割と仕様を定義する．

---

## 📂 lib (共通ユーティリティ)

コンポーネントやフックから呼び出される，特定の機能に依存しない純粋な補助関数を提供する．

### `fetcher.ts`

- **概要**：SWR などのデータ取得ライブラリから呼び出される，標準的な HTTP GET 要求処理器（フェッチャー）である．
- **引数**：`url: string`（要求先のAPI経路）
- **戻り値**：`Promise<any>`（応答の実データ部分）
- **論理詳細**：
  1. **HTTP通信**：標準の `fetch` API を用いて指定されたURLへGET要求を送信する．
  2. **通信レベルの異常検知**：HTTPステータスコードが 200 番台以外（`!res.ok`）の場合，即座に例外を投げる（スローする）．
  3. **アプリケーションレベルの異常検知**：応答を JSON として解釈し，バックエンドが定める共通応答形式の `success` 属性が `false` であった場合，API側が提示したエラーメッセージを用いて例外を投げる．
  4. **データ抽出**：検証に成功した場合，応答内の `data` 属性の中身のみを抽出して返却する．これにより，呼び出し元（各カスタムフック）は常に純粋なデータ実体のみを受け取ることができる．

## 📂 types (型定義)

TypeScript コンパイラに対し，プロジェクト固有の型情報や，型定義を持たない外部ライブラリの構造を教えるための定義群である．

### `global.d.ts`

- **概要**：`window` オブジェクトや JSX 要素など，グローバル空間に存在する実体の型を拡張・補完するファイルである．
- **定義詳細**：
  - **`Window` インターフェースの拡張**：
    - `AFRAME`, `MeshoptDecoder` など，AR画面の初期化時に動的ロードスクリプトによって `window` 上に直接展開される外部ライブラリの実体を定義し，コンパイル時の警告を防ぐ．
    - `_loadingManager` のように，Three.js の読み込み進捗を横断的に管理するために独自に生やした一時プロパティの型を定義する．
  - **外部ライブラリの名前空間定義**：
    - `AFRAME` および `THREE` の名前空間を宣言し，内部で使用する関数（`registerComponent` 等）や拡張されたローダー（`GLTFLoader`, `DRACOLoader` 等）の存在を保証する．
  - **`ASceneElement` インターフェース**：
    - A-Frame の `<a-scene>` 要素を表現する独自の DOM 要素型．MindAR 拡張によって追加される `systems` プロパティ（`mindar-image-system` の `start()`, `stop()` 関数など）の構造を定義し，ARエンジンの安全な制御を可能にする．
  - **JSX 組み込み要素の拡張**：
    - React は標準で HTML5 のタグしか認識しないため，A-Frame 固有のタグ（`<a-scene>`, `<a-entity>`, `<a-camera>`, `<a-light>`, `<a-gltf-model>`）を JSX 内で使用してもエラーにならないよう，`JSX.IntrinsicElements` に対してそれらのタグ名と許容される属性（`position`, `rotation`, `mindar-image-target` など）を追加登録している．
