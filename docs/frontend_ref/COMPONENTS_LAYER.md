# 🖥️ フロントエンド・リファレンス：Components Layer (UI部品)

本ドキュメントは，`frontend/components/` 配下に配置されている，再利用可能な UI コンポーネント群の役割と仕様を定義する．これらは純粋な表示ロジックやアニメーション演出を担い，状態管理（Hooks）や画面（App Layer）から分離されている．

---

## 📂 共通コンポーネント

### `BadgeCard.tsx`
- **概要**：ホーム画面（冒険者の手記）において，単一の標本（アート作品）の状態を表示するためのカード型コンポーネントである．
- **引数 (Props)**：
  - `badge: Badge`（表示対象の標本実体）
  - `isAcquired: boolean`（この標本が既に獲得済みであるかを示すフラグ）
  - `acquiredAt: string | null`（獲得日時．未獲得の場合は null）
- **論理詳細**：
  - `isAcquired` が `true` の場合，フルカラーで絵画画像（`image_url`）を表示し，発見日時や「データ復元完了」といった装飾を描画する．
  - `false`（未獲得）の場合，グレースケールやセピア調のフィルターを適用し，ミステリアスな未発見状態を演出する．
  - 標本の種類（`target_index`）に応じて，Lucide React の異なるアイコン（例：蝶，クジラ，剣）を動的に割り当てて表示する．

## 📂 ar (AR画面用部品)

AR体験中に，カメラ映像（A-Frame / MindAR）の上に被せて表示するオーバーレイ（重ね合わせ）UIを提供する．

### `DiscoveryComplete.tsx`
- **概要**：AR空間で標本を捉え，解析が100%に達した瞬間に全画面で表示される「獲得成功ダイアログ」である．
- **引数 (Props)**：
  - `badgeName: string`（発見した標本の名称）
  - `artistName: string | undefined`（作者名）
  - `allBadges: Badge[]`（全標本の目録）
  - `acquiredBadgeIds: string[]`（これまでに獲得した標本IDの配列）
  - `isLast: boolean`（これが最後の1つ＝コンプリートであるかを示すフラグ）
  - `isExchanged: boolean`（景品交換済みであるか）
  - `onClose: () => void`（「手記に記録する」ボタン押下時のコールバック）
- **論理詳細**：
  - Framer Motion を利用し，下から浮き上がる（slide-up）滑らかなアニメーションと共に登場する．
  - 現在の総獲得数を算出し，「2 / 6」のような進捗状況をプログレスバーと共に表示する．
  - `isLast` が真の場合，通常の閉じるボタンに代わり，「景品受け取り場所へ向かう」などの特別なメッセージと演出に切り替わる．

### `SpecimenRegistrationLabel.tsx`
- **概要**：AR体験中に画面の隅に常に表示される，現在のステータス（標本登録状況）を示す小さなラベルである．
- **引数 (Props)**：
  - `acquiredCount: number`（現在獲得済みの数）
  - `totalCount: number`（全体の目標数）
- **論理詳細**：
  - 単純な表示部品であり，「標本登録中 3/6」のようなテキストを固定のスタイル（半透明の黒背景など）で描画する．

## 📂 journal (手記画面用部品)

ホーム画面（冒険者の手記）内で使用される特別な演出部品である．

### `FinalLogModal.tsx`
- **概要**：すべての標本を獲得（コンプリート）した利用者が，ホーム画面に戻ってきた際に一度だけ表示される特別なモーダル（ポップアップ）画面である．
- **引数 (Props)**：
  - `isOpen: boolean`（モーダルの表示・非表示を制御する状態）
  - `isExchanged: boolean`（すでに景品交換済みであるかを示すフラグ）
  - `onClose: () => void`（モーダルを閉じる際のコールバック）
  - `onExchange: () => void`（「景品を受け取った」ボタンを押下した際のコールバック）
- **論理詳細**：
  - Framer Motion によるスケール（拡大）アニメーションと背景のフェードインを行う．
  - `isExchanged` が偽の場合，「スタッフにこの画面を見せてください」という警告と，交換を実行するための大きなボタンを表示する．
  - 交換ボタンが押下されると `onExchange` が発火し（裏側でAPIが呼ばれ），画面が「交換完了」の表示に切り替わる．

## 📂 layout (レイアウト部品)

### `CloseButton.tsx`
- **概要**：AR画面やビューアー画面から，直前の画面（またはホーム画面）に戻るための「×」ボタンである．
- **引数 (Props)**：
  - `onClick: () => void`（クリック時のコールバック関数）
- **論理詳細**：
  - 画面の右上に固定配置（`fixed`, `top-4`, `right-4`）され，ガラス効果（`backdrop-blur`）を伴う円形のデザインを提供する．

### `AppHeader.tsx` / `AppFooter.tsx`
- **概要**：ホーム画面や管理画面で共通して使用されるヘッダーおよびフッターである．
- **論理詳細**：
  - プロジェクトのロゴや著作権表記，ナビゲーションリンクなどを静的に描画する．
