# 🖥️ フロントエンド・リファレンス：Public Assets Layer (静的資産)

本ドキュメントは，`frontend/public/` 配下に配置されている静的ファイル（画像，3D模型，AR標的，外部スクリプト）の構成と役割を定義する．これらはビルド処理を経ずに，指定された経路（パス）からブラウザへ直接配信される．

---

## 📂 3D Models (標本模型)

AR 空間上に投影される実体となる 3D 模型ファイル群である．これらは glTF (GL Transmission Format) のバイナリ形式である `.glb` として最適化されている．

### 一覧と役割

| ファイル名      | 対応する作品名           | 概要                               |
| :-------------- | :----------------------- | :--------------------------------- |
| `butterfly.glb` | 自然に寄り添う者たち     | 蝶の3D模型．                       |
| `whale.glb`     | お母さんの初水族館       | クジラの3D模型．                   |
| `shellcrab.glb` | ちょっと不思議な海の冒険 | ヤドカリ（貝殻カニ）の3D模型．     |
| `sword.glb`     | 海底の奥                 | アンティークな剣の3D模型．         |
| `wave.glb`      | よすが                   | 波（Great Wave）を表現した3D模型． |
| `jellyfish.glb` | 遊々海月                 | クラゲの3D模型．                   |

- **運用詳細**：これらの模型を直接読み込むとファイル容量が大きくなる場合があるため，必要に応じて `meshopt` や `draco` 等の圧縮技術が適用されており，ブラウザ側でデコーダーを用いて展開される．

## 📂 AR Targets (AR標的情報)

MindAR エンジンがカメラ映像から現実の絵画を認識するための特徴点データである．

### `targets.mind`

- **概要**：6つの絵画（作品）すべての特徴点情報を1つのバイナリファイルにコンパイルしてまとめたものである．
- **論理詳細**：
  - AR画面（`<a-scene>`）の初期化時に `mindar-image` 属性を通じて読み込まれる．
  - 内部には `0` から `5` までのインデックス（`target_index`）が割り当てられており，各インデックスが特定の絵画に対応している．
  - カメラが特定の特徴点を捉えると，対応する `target_index` のイベント（`targetFound`）が発火し，そこに紐付く 3D 模型が投影される仕組みである．

## 📂 images (画像資産)

アプリケーション内で使用される 2D 画像群である．

### `images/paintings/`

- **概要**：各標本の元となった現実の絵画画像が格納されている．
- **一覧**：`painting_0.jpg` 〜 `painting_5.jpg`
- **用途**：
  - ARマーカー（ターゲット）の視覚的な確認用．
  - ホーム画面（冒険者の手記）において，発見済みの標本を一覧表示する際のサムネイル画像として使用される．

## 📂 scripts (外部依存スクリプト)

NPM パッケージとして取り込むことが困難な，あるいは `<script>` タグによる直接的なグローバル展開が必須な外部ライブラリ群である．

### A-Frame および AR 関連

- **`aframe.min.js`**：WebVR / WebAR を実現するための根幹となる 3D 描画枠組み（フレームワーク）である．
- **`aframe-extras.min.js`**：A-Frame にアニメーション制御（`animation-mixer`）などの拡張機能を提供する．
- **`mindar-image-aframe.prod.js`**：A-Frame と連携して画像認識（イメージトラッキング）AR を実現する MindAR エンジンの本体である．

### 3D 圧縮解除（デコーダー）関連

- **`draco_decoder.js` / `draco_decoder.wasm` / `draco_wasm_wrapper.js`**
  - **概要**：Google の Draco 圧縮技術によってサイズが縮小された 3D 模型を，ブラウザ上で展開するためのスクリプト群である．
- **`meshopt_decoder.js`**
  - **概要**：Meshoptimizer によって最適化・圧縮された 3D 模型の頂点データやインデックスを展開するためのスクリプトである．
- **運用詳細**：これらのデコーダーは，AR 画面の初期化時に `THREE.GLTFLoader` のプロトタイプを拡張することでシステムに組み込まれ，圧縮された `.glb` ファイルを自動的に展開する．
