# 🖥️ フロントエンド・リファレンス：Hooks Layer (状態・通信管理)

本ドキュメントは，`frontend/hooks/` 配下に配置されているカスタムフックの仕様を定義する．これらは React コンポーネントから複雑な非同期処理（API通信やARエンジンの制御）を分離し，再利用可能な論理として提供する．

---

## 📂 カスタムフック

### `useAR.ts`
- **概要**：ARカメラ画面（`/ar`）における主要な論理（トラッキング監視，標本獲得，状態管理）を提供するカスタムフックである．外部ライブラリ（MindAR, A-Frame）との連携や，SWRを通じたデータ取得の橋渡しを担う．
- **戻り値**：
  - `status`: ARエンジンの準備状態（"idle", "loading", "started"）
  - `modelProgress`: 3Dモデルの読み込み進捗率（0-100）
  - `isFound`: カメラが標本を捉えているかどうかの状態
  - `progress`: 発見中標本の解析（獲得）進捗率（0-100）
  - `acquired`: 現在捉えている標本がすでに獲得済みかどうかの状態
  - `showSuccess`: 獲得成功ダイアログの表示状態
  - `activeBadge`: 現在カメラが捉えている標本実体
  - その他：全標本目録，獲得済み標本識別子配列，各種コールバック関数
- **論理詳細**：
  1. **データ同期**: SWRを用いて，全標本マスタ，獲得済み履歴，プロフィール情報を並列に取得する．
  2. **トラッキング監視**: A-Frameから発行される `targetFound` および `targetLost` イベントを監視し，対象の標本を特定して `isFound` や `activeBadge` 状態を更新する．
  3. **プログレス管理**: 標本を発見中，`requestAnimationFrame` を用いて解析ゲージ（`progress`）を時間経過と共に上昇させる．カメラから外れるとゲージは初期化される．
  4. **永続化**: ゲージが100%に達し，かつ未獲得の標本であった場合，`/api/v1/badges/acquire` へPOST要求を送信して獲得記録を保存し，SWRキャッシュを再検証する．

### `useHome.ts`
- **概要**：ホーム画面（「冒険者の手記」画面）のライフサイクルと状態管理を統合するフックである．匿名認証の自動実行や，標本リストの並び替え論理を含む．
- **戻り値**：
  - `sortedBadges`: 獲得状況と日時を考慮して並び替えられた標本目録
  - `acquiredBadgeIds`: 獲得済み標本の識別子配列
  - `initialLoading`, `syncing`: 初期読み込み中やバックグラウンド同期中の状態
  - `hasSubmittedPartySize`: 人数入力が完了しているかどうかの判定
  - `profile`: 利用者の属性情報
  - `submitPartySize(size)`: 人数入力を送信する関数
  - `markAsExchanged()`: 景品交換完了を記録する関数
  - `requestCameraPermission()`: カメラ権限を要求する関数
- **論理詳細**：
  1. **セッションとキャッシュの同期**: `supabase.auth.onAuthStateChange` を監視し，認証状態の変化に応じてセッション情報を更新する．サインアウト時は機密データ保護のためキャッシュを即座に破棄する．
  2. **ソート（並び替え）論理**:
     - 第一優先：すでに獲得済みの標本を上に配置する．
     - 第二優先：獲得済み同士の中では，獲得日時が新しいもの（直近で発見したもの）を上に配置する．
     - 未獲得の標本は元の順序（`target_index`）に従う．
  3. **人数送信と遅延初期化**: `submitPartySize` 実行時，利用者が未ログインであれば `signInAnonymously()` を呼び出して背後で匿名アカウントを自動作成し，その後プロフィールを更新する．

### `useBadges.ts`
- **概要**：標本データの取得およびSWRのキャッシュ管理を担うフック群を提供する．
- **提供関数**：
  - **`useBadges()`**
    - 全標本マスターデータを取得する．
    - `dedupingInterval` を 60000（1分）に設定し，短期間の重複リクエストを統合して通信量を削減する．
  - **`useAcquiredBadges(userId)`**
    - 特定利用者の獲得済み標本履歴を取得する．
    - `revalidateOnFocus` を有効にし，AR画面からホーム画面に戻った際に最新の獲得状況が即座に反映されるように構成されている．

### `useProfile.ts`
- **概要**：特定利用者のプロフィール情報（人数設定など）を管理するフックである．
- **引数**：`userId: string | undefined`
- **戻り値**：
  - `profile`: 現在のプロフィールデータ実体
  - `isLoading`, `isError`: ロード状態とエラー情報
  - `updateProfile(updates)`: プロフィールを更新する関数
  - `refresh()`: キャッシュを手動で最新化する関数
- **論理詳細**：
  - `/api/v1/profile/get` を介してデータを取得し，キャッシュする．
  - `updateProfile` 実行時，`/api/v1/profile/update` へ通信を行い，成功した場合は `mutate()` を呼び出して自身のキャッシュを再検証し，UIを最新状態に同期する．
