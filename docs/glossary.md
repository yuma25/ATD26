# 📖 用語集 (Glossary)

本プロジェクトで使用される主要な用語および略称の定義を記載する。

| 用語 / 略称                      | 意味                                        | 解説                                                                                                                             |
| :------------------------------- | :------------------------------------------ | :------------------------------------------------------------------------------------------------------------------------------- |
| **AR (Augmented Reality)**       | 拡張現実                                    | 現実世界にデジタル情報を重ね合わせて表示する技術。本プロジェクトでは MindAR および A-Frame を使用している。                      |
| **MindAR**                       | WebベースのARライブラリ                     | 画像追跡（Image Tracking）に特化したARライブラリ。                                                                               |
| **A-Frame**                      | WebVRフレームワーク                         | HTMLベースで 3D/VR コンテンツを作成するためのフレームワーク。AR描画の基盤として使用。                                            |
| **Specimen (標本)**              | 作品/標本                                   | 本アプリで収集対象となる 3D モデルデータおよびそのメタデータ。内部的には `Badge` エンティティとして管理される。                  |
| **Badge (バッジ)**               | 獲得実績                                    | ユーザーが特定の標本（作品）を発見し、解析を完了した際に付与されるデジタルな証明。                                               |
| **Profile (プロフィール)**       | ユーザー情報                                | 匿名認証された各ユーザーの属性情報。パーティー人数や景品交換状況などを含む。                                                     |
| **SWR (Stale-While-Revalidate)** | データ取得戦略                              | キャッシュからデータを返しつつ、バックグラウンドで再検証（最新化）を行う HTTP キャッシュ無効化戦略、またはそのためのライブラリ。 |
| **BaaS (Backend as a Service)**  | サーバー側機能提供サービス                  | データベース（Supabase）やキャッシュ（Upstash）など、インフラ管理を必要としないサービス群。                                      |
| **Supabase**                     | Firebase 代替のオープンソース BaaS          | PostgreSQL データベース、認証、リアルタイム通信機能を提供するプラットフォーム。                                                  |
| **Redis / Upstash**              | キーバリューストア                          | 高速なデータアクセスを可能にするインメモリデータベース。本プロジェクトでは API レスポンスのキャッシュに使用。                    |
| **Zod**                          | TypeScript First のバリデーションライブラリ | API の入出力データの型安全性を実行時に保証するために使用。                                                                       |
| **GLB / GLTF**                   | 3Dモデルフォーマット                        | Web で標準的に使用される 3D アセットのフォーマット。                                                                             |
| **Marker (マーカー)**            | 追跡対象画像                                | AR カメラが認識するための特定の画像。これに紐付いて 3D モデルが表示される。                                                      |
| **Analysis Gauge (解析ゲージ)**  | 解析進捗                                    | ユーザーがマーカーにカメラを向け続けている間に蓄積される進捗。100%になると標本が獲得される。                                     |
| **SoC (Separation of Concerns)** | 関心の分離                                  | システムを独立した機能単位に分割し、各部分の責務を明確にする設計原則。                                                           |
| **SSR (Server-Side Rendering)**  | サーバーサイドレンダリング                  | サーバー側で HTML を生成してクライアントに送信する手法。                                                                         |
| **CSR (Client-Side Rendering)**  | クライアントサイドレンダリング              | ブラウザ側で JavaScript を実行して UI を構築する手法。                                                                           |
